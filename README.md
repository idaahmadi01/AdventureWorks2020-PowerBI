# Adventure Works | Power BI Dashboard

This project is an interactive Power BI dashboard built using the Adventure Works dataset. The goal was to turn raw sales data into a clear, easy-to-navigate report that helps users understand business performance, customer behavior, and product profitability.

The dashboard is organized into three main pages:

- **Sales Overview:** Tracks key metrics such as total sales, orders, revenue trends, and profit, with breakdowns by product category and country.
- **Customer Analysis:** Explores customer demographics, income levels, occupations, purchasing behavior, and monthly customer growth.
- **Product Analysis:** Highlights best-selling products, sales by subcategory, profit margins, and detailed product-level performance.

I used **DAX** to create measures for KPIs, profitability, customer growth, and purchasing patterns. I also added interactive slicers, page navigation, reset filters, and custom tooltips to make the report easier to explore.

One of my main priorities was keeping the dashboard both functional and visually consistent. I wanted users to be able to move between different areas of the business, compare results, and find useful insights without getting overwhelmed by too many visuals.

**Tools & Skills:** Power BI Desktop, Power Query, DAX, Data Modeling, Data Visualization, Dashboard Design, and Interactive Reporting.
